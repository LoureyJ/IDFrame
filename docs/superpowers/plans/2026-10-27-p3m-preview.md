# Host-only P3M comparison preview

The user asked for a preview to test the trained candidate after discussing an
optional model rather than automatic promotion. Add **Test P3M** after background
removal on the source host, where the local candidate exists. Compare the current
applied result with P3M using identical crop/brightness and white export geometry.
Keep current/close discards the candidate; **Use P3M for this photo** commits it
without changing the default removal mode. The normal editor and Save remain
available after applying it.

Run inference and both comparison renders through the existing background worker.
Use a separate modal comparison dialog with cached Qt images; no work runs in
its paint/resize handlers. Reject stale completions and avoid opening a dialog
while the application is closing. Missing/failed model operations preserve the
current result. Candidate weights stay under ignored build/p3m-review/full, so
this experiment does not enter the client payload or replace either active model.
